
## 🎯 OOP Concepts Covered

| Concept | Example Files |
|---------|---------------|
| **Classes & Objects** | All files demonstrate class creation and object instantiation |
| **Constructors** | `Constructor.java`, `Constructor_1.java` - Parameterized and default constructors, constructor overloading |
| **Encapsulation** | `Bank.java`, `BankAccount.java` - Data hiding with methods for controlled access |
| **Static Members** | `Employee.java`, `Student.java`, `Movie.java` - Class variables and methods shared across instances |

| **Object References** | `Constructor.java`, `StudentClass.java` - Passing objects to methods |

| **This Keyword** | Multiple files - Referring to current instance |

## 📋 Detailed File Descriptions

### 🏗️ Basics & Class Fundamentals

| File | Description |
|------|-------------|
| **Basic.java** | Simple "Hello World" program demonstrating basic Java class structure and main method. |
| **Student.java** | Complete student management system with ID, name, department, CGPA, static university variable, and total student counter. Uses Scanner for interactive input. |
| **StudentClass.java** | Demonstrates object mutation by passing a Student object to a method that modifies its properties. Shows how objects are passed by reference in Java. |
| **Rectangle.java** | Geometry calculator with Length/Width fields, Area() and Perimeter() methods, and user input for dimensions. |

### 🔧 Constructors

| File | Description |
|------|-------------|
| **Constructor.java** | Demonstrates parameterized constructor with Student class (name, id, age, home). Includes a `change()` method that modifies object properties, showing pass-by-reference behavior. |
| **Constructor_1.java** | Complete example of constructor overloading with both parameterized and default constructors. Includes display method to show object state. |

### 💼 Real-World Applications

| File | Description |
|------|-------------|
| **Employee.java** | Professional employee management system with name, age, designation, salary. Features static company information (name, address, total employees) and interactive input for multiple employees. |
| **Bank.java** | Simple banking system with account number and balance. Provides deposit/withdraw functionality with balance checking before withdrawal. |
| **BankAccount.java** | Enhanced banking with package structure, validation (positive amounts, sufficient balance), and proper error messages. Uses long data type for balance. |
| **Movie.java** | Hybrid employee/movie class with static company details and employee counter. Demonstrates class variables and methods. |
| **MovieDetails.java** | Driver class that tests the Movie class by creating multiple employee objects and displaying their details along with company statistics. |
