## 📌 Overview

This repository contains a **curated collection of Java programs** that illustrate fundamental and advanced **Object-Oriented Programming (OOP)** concepts. It is designed for students, educators, and Java enthusiasts who want to learn through practical examples.

The code covers:
- Classes and objects
- Constructors and constructor overloading
- Encapsulation, inheritance, and polymorphism
- Abstraction and interfaces
- Real‑world mini‑projects (Bank, Employee, Movie systems)

All programs are written in **Java** and are organised by topic for easy navigation.

---

## 📂 Repository Structure

The repository is organized by concept or file type. Below is a high‑level overview:

| Category | Description |
|----------|-------------|
| **Basics & Class Fundamentals** | Basic syntax, class structure, objects, and methods. |
| **Constructors** | Parameterized, default, and overloaded constructors. |
| **Real-World Applications** | Mini projects simulating real systems (Bank, Employee, Movie). |
| **Inheritance & Polymorphism** | Base and derived classes, method overriding, and multi‑level inheritance. |
| **Abstraction & Interfaces** | Abstract classes, interfaces, and shape calculators. |
| **Q&A / Practice Files** | Sequential practice files and Q&A programs for self‑assessment. |

## 💻 Detailed File Descriptions

### 🏗️ Basics & Class Fundamentals

| File | Description |
|------|-------------|
| `Basic.java` | Simple "Hello World" program demonstrating basic Java class structure and the `main` method. |
| `Student.java` | Complete student management system with ID, name, department, CGPA, static university variable, and total student counter. Uses `Scanner` for interactive input. |
| `StudentClass.java` | Demonstrates object mutation by passing a `Student` object to a method that modifies its properties. Shows how objects are passed by reference in Java. |
| `Student_Details.java` | Extended student management with additional fields and methods for detailed student records. |
| `Student_Details_1.java` | Another variation of student details, showcasing different approaches to data handling. |
| `Rectangle.java` | Geometry calculator with Length/Width fields, `Area()` and `Perimeter()` methods, and user input for dimensions. |

### 🔧 Constructors

| File | Description |
|------|-------------|
| `Constructor.java` | Demonstrates a parameterized constructor with the `Student` class (name, id, age, home). Includes a `change()` method that modifies object properties, showing pass‑by‑reference behavior. |
| `Constructor_1.java` | Complete example of constructor overloading with both parameterized and default constructors. Includes a `display()` method to show object state. |

### 💼 Real-World Applications

| File | Description |
|------|-------------|
| `Employee.java` | Professional employee management system with name, age, designation, and salary. Features static company information (name, address, total employees) and interactive input for multiple employees. |
| `Bank.java` | Simple banking system with account number and balance. Provides deposit/withdraw functionality with balance checking before withdrawal. |
| `BankAccount.java` | Enhanced banking with package structure, validation (positive amounts, sufficient balance), and proper error messages. Uses `long` data type for balance. |
| `Movie.java` | Hybrid employee/movie class with static company details and employee counter. Demonstrates class variables and methods. |
| `MovieDetails.java` | Driver class that tests the `Movie` class by creating multiple employee objects and displaying their details along with company statistics. |

### 🧬 Inheritance & Polymorphism

| File | Description |
|------|-------------|
| `Animal.java` | Base class demonstrating inheritance. Contains fields and methods that can be overridden by subclasses. |
| `Animal_1.java` | Extended animal class showcasing method overriding and polymorphic behavior. |
| `Person.java` | Base class for person‑related hierarchies, demonstrating core inheritance principles. |
| `Dog.class` | Compiled subclass example (source may be in a `.zip` file) showing inheritance from `Animal`. |
| `Inheritance.zip` / `Inheritance_1.zip` / `Inheritance_2.zip` / `Inheritance_3.zip` | Archived projects with complete inheritance hierarchies, including multi‑level and hierarchical inheritance examples. |

### 🎨 Abstraction & Interfaces

| File | Description |
|------|-------------|
| `Abstruction.zip` | Archived project demonstrating abstract classes and methods. |
| `Shape.zip` / `ShapeCalculator.zip` | Geometry projects using abstract classes to define common shapes and calculate area/perimeter. |
| `InterfaceDemo.zip` | Archived project showcasing interface implementation and multiple inheritance through interfaces. |

### ❓ Question & Answer / Practice Files

| File | Description |
|------|-------------|
| `QNA_1.java` / `QNA_2.java` | Practice programs covering various OOP concepts, often used for lab sessions or self‑assessment. |
| `A.java` / `B.java` / `C.java` / `D.java` / `E.java` | Sequential practice files covering different OOP topics — from basic syntax to advanced concepts. |
